## Как думаю о работе

- **Сначала спек, потом код.** Короткий документ по реальному репозиторию: что меняется, какие инварианты, как проверить. Пишется до первой правки.
- **Проверяемость важнее скорости.** Автотесты на критичные места (синхронизация, git-конвейер, дизайн-контракт), локальный CI-гейт перед коммитом.
- **Мелкие атомарные коммиты.** История — инструмент отката, а не журнал активности.
- **Контракт важнее вкуса.** Цвет, радиус, длительность анимации сначала появляются как токен, потом в разметке. Запреты тоже явные: без градиентного «AI-slop», без случайных теней.

Крупную фичу режу так же, как потом зашил в VibeForge: формулировка результата → спек → эпики → параллельная работа в отдельных git worktree → линт → тесты → коммит только с зелёным CI → ревью диффа → merge по одному.

## Что уже сделал

**FlexPlan** — планировщик, в котором у задач есть длительность. Offline-first синхронизация с очередью мутаций и tombstones, свой realtime на WebSocket без Redis, общее доменное ядро на веб и мобайл, подписка и Pro-гейт. В проде.

**VibeForge** — харнес над CLI-агентами (Claude Code, Codex, Grok и другие): четыре режима оркестрации, изоляция через git worktree, локальный CI перед коммитом, нормализация разнородных протоколов в одну модель событий. Сборки под macOS и Windows; рядом iOS-компаньон на Swift.

Раньше — Telegram-боты и прототипы на Python (игры, новости, загрузка видео), календарный таск-менеджер, из которого вырос FlexPlan.
