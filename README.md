## Флагманские продукты

### 1. FlexPlan — планировщик, где у задач есть длительность

Задачи раскладываются по часам на календаре (день / неделя / месяц / год), поэтому сразу видно,
что реально влезает в день. Вокруг календаря — буфер задач, канбан-доски, заметки с вики-ссылками и
графом, трекер привычек, фокус-таймер, AI-ассистент, командные пространства, статистика и Pro-подписка.

**Платформы:** веб + PWA, нативная обёртка для macOS (Tauri 2), мобильное приложение на Expo/React Native.

**Технически интересное:**

- **Offline-first синхронизация.** Приложение полностью работает без сети и без аккаунта; мутации
  копятся в локальной очереди и доигрываются при появлении сети. Разрешение конфликтов — row-level
  last-write-wins по `updated_at` с tombstones для удалений, чтобы удалённая на одном устройстве
  сущность не «воскресала» с другого.
- **Свой realtime** на WebSocket без Redis: сервер рассылает минимальное событие «что изменилось в
  каком пространстве», клиент до-пуливает только затронутый скоуп. Реконнект с backoff.
- **Аутентификация** на коротком access-JWT + refresh-токене в httpOnly-cookie с прозрачным обновлением
  на 401 (и отдельной ветвью для десктопа, где cookie недоступны).
- **Биллинг и Pro-гейт** на уровне middleware, автопродление по расписанию, вебхуки платёжного провайдера.
- **Общее ядро домена** вынесено в отдельный пакет и потребляется как TypeScript-исходники сразу двумя
  сборщиками — Vite (веб) и Metro (мобайл), без дублирования логики синхронизации и API-клиента.
- **Живучесть фронтенда:** boot-watchdog на случай, если бандл не поднялся, и self-heal устаревшего
  service worker — после деплоя упавший lazy-import чинится сбросом кэша и одним контролируемым reload.

**Метрики репозитория** (снимок git на 25.07.2026): ~2 650 коммитов, ~42 000 строк TypeScript,
23 таблицы в PostgreSQL, 61 UI-компонент, 14 модулей API-роутов, доменное ядро ~8 000 строк.

### 2. VibeForge — оркестратор AI-агентов для реального кода

Десктопное приложение (macOS + Windows): одна задача текстом превращается в работу команды
AI-агентов над вашим репозиторием — с изоляцией через git, автотестами, ревью диффа до коммита и
осмысленной историей коммитов. Агенты — headless-процессы уже установленных у пользователя CLI
(Claude Code, Codex, Grok, Kimi, Gemini) под его подписками; продукт — харнес над ними: планирование,
параллельность, изоляция, гейты, наблюдаемость, восстановление после сбоев.

**Технически интересное:**

- **Четыре режима оркестрации.** Solo (один агент в проекте), Swarm (до 6 агентов в одной папке с
  общим чатом, разделением файлов и файловым watcher-ом), Fusion (многомодельный дебат в три
  раунда — предложение, критика, конвергенция — а затем отдельный агент-синтезатор реализует
  решение) и Orchestrator (планировщик режет цель на эпики, каждый эпик уходит в собственный
  git worktree вне проекта).
- **Конвейер качества в Orchestrator:** итерация агента → локальный CI (install / lint / test) →
  коммит только при зелёном CI → ручное ревью диффа в Monaco → merge строго по одному под мьютексом.
  Провал CI возвращается агенту как фидбек (до 5 итераций), конфликт слияния поднимает отдельного
  resolver-агента.
- **Абстракция над разнородными движками:** нормализация stream-json-протоколов нескольких CLI и
  API-провайдеров в одну модель событий (логи, терминалы, канбан, учёт токенов), плюс живой steering
  — сообщение уходит агенту в текущий ход, если протокол это позволяет.
- **Устойчивость к rate-limit подписок:** приложение парсит время сброса лимита из ошибки, ждёт и
  автоматически возобновляет ту же беседу агента вместо провала задачи.
- **Безопасность как явный слой:** все пути от модели проходят realpath + проверку префикса рабочей
  директории (блокирует `..`, абсолютные пути и symlink-побеги), выполнение команд — с таймаутом и
  блок-листом, внешние расширения ставятся только после явного подтверждения пользователя и с
  проверкой контрольной суммы бандла.
- **Продукт вокруг продукта:** нативный iOS-компаньон со виджетом на Swift, relay-туннель для
  удалённого управления сессиями с телефона, лицензирование, сборка релизов под macOS и Windows,
  лендинг и промо-ролики на Remotion — всё в одном монорепозитории.
- **Дизайн-контракт** зафиксирован документом и проверяется автотестом: единая палитра, шкала
  типографики и радиусы для приложения, лендинга и видео.

**Метрики репозитория** (снимок git на 25.07.2026): ~420 коммитов за 2 недели активной разработки,
~49 000 строк TypeScript, ~8 500 строк Swift, Rust-слой Tauri, 12 таблиц SQLite и 21 миграция,
106 файлов самотестов.

[Полный разбор →](projects/vibeforge.md)

## Как я работаю

- **Сначала спек, потом код.** У обоих флагманов есть живой архитектурный документ, составленный по
  реальному коду и перепроверяемый чтением файлов, а не по памяти. У UI — отдельный дизайн-контракт:
  новый цвет или радиус сначала появляется как токен, потом в разметке.
- **Проверяемость важнее скорости.** Автотесты и самотесты на критичные инварианты (git-конвейер,
  протокол синхронизации, дизайн-контракт), локальный CI-гейт перед коммитом.
- **Мелкие атомарные коммиты** с говорящими сообщениями: история — это инструмент отката, а не журнал.
- **Продуктовое мышление.** Я не только пишу код, но и решаю, что именно стоит писать: позиционирование,
  паспорт фич, лендинг, промо-видео, цена и биллинг — часть той же работы.
